## AI 활용 역량

- **AI 도구 자산화**: 프레임워크 변환·분석·설계 등 반복 업무를 Claude Code 커스텀 스킬 7종으로 자동화해 실전 운영
- **MCP 서버 개발·배포**: AI 사용량 집계(Tokenbill)·AI 활용 이력서 자동화(AICV) 서버 2종을 직접 개발, CI/CD·AWS로 공개 운영 중
- **에이전트 워크플로 운영**: 장기 자율 에이전트 세션을 상시 운용 — 서브에이전트 위임·병렬 도구 호출로 독립 작업 동시 진행
- **검증 중심 AI 개발**: AI 산출물을 실행·테스트로 확인하며 진행하는 워크플로 정착
- **전 영역 적용**: Java 백엔드 중심으로 프론트·인프라·SQL·문서까지 17개 프로젝트에 적용

### 대표 활용 사례

- **레거시 프레임워크 전환 POC (국내 생명보험사)** — 코어 시스템 프레임워크 전환을 위해 Bean·DBIO·서비스·배치 영역별 변환 스킬을 직접 제작, 소스 전처리부터 505개 파일 일괄 변환·컴파일 검증과 산출물 등급 평가까지 AI 파이프라인으로 수행
- **분석서·설계서 자동 생성·평가 루프** — 전환 대상 소스에서 분석·설계 문서를 자동 생성하는 스킬을 만들고 품질 평가·보완 루프 운영, 전환 방향 발표 PPT·결과 보고서 작성까지 일원화
- **AI 서비스 기획→운영 완결 (개인 프로젝트)** — AI 비용 대시보드(Tokenbill)와 AI 활용 이력서 자동화(AICV)를 스키마 설계부터 CI/CD·AWS 배포·도메인 연결까지 전 과정 AI 협업으로 완성, 실서비스 운영 중
