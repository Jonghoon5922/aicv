AICV

많이 썼다(리더보드)도, 시험 쳤다(자격증)도 아닌 — 실제 작업 로그가 AI 활용 능력을 증명합니다. 지속 업데이트되는 이력서.

시작하기

1. 업로드 토큰

MCP가 증거 팩을 올릴 때 쓰는 열쇠입니다.

아직 발급 전

2. MCP 연결

①레포 클론: git clone https://github.com/Jonghoon5922/aicv
②등록:
claude mcp add aicv -- node <클론 경로>/index.js
③새 세션에서 /aicv — 이력서 생성 후 "포탈에 올려줘"

3. 공개 프로필

마지막 업로드: 없음 · 로그아웃

어떻게 동작하나요?

수집MCP가 로컬 AI CLI 로그를 스캔 — 대화 원문 없이 집계값만
작성Claude가 증거 팩을 근거로 이력서 문장 작성 (rubric 점수는 규칙 기반)
증명공개 프로필 링크 하나로 공유 — 실행할 때마다 성장 델타 갱신

프라이버시: 실제 경로·원문이 포함된 팩은 서버가 거부합니다. 프로필은 기본 비공개입니다.
